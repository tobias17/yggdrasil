# Islands

This folder focuses on creating floating islands models.

The island generation tool takes in a diameter and height parameter to generate an island with.

The top of the island is flat within this diameter, but below the top it might bulge out slightly more than the diameter.

The height is a rough estimate for the size, and the actual height can vary slightly.

The idea behind this is to generate a bunch of different looking but roughly the same sized islands given a set of parameters.
